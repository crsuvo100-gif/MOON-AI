# scripts/

Utility & maintenance scripts for MOON-AI:

- **deploy.sh** — one-click deployment
- **setup-cybersecurity-mode.sh** — toggle cybersecurity mode
- **uninstall_moon.py** — safe uninstaller
- **.scan_imports.py** — dependency scanner
- **example.py**, **script.py** — usage examples
- **gen_model_registry.py** — model registry generator

Each script is self-contained and documented inline.
